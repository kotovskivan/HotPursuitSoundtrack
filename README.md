# Hot Pursuit Soundtrack — coming soon

Your own songs in **Need for Speed Hot Pursuit** (2010) and **Hot Pursuit Remastered** (PC) — as new tracks in races and pursuits,
next to the game's music. One program for both versions.
Free fan-made tool by **Kitivski + Claude** (Claude — AI by Anthropic). Not affiliated with Electronic Arts, Criterion Games or Stellar Entertainment.

**Status:** in progress. We've figured out how the game stores its music; the first version of the program exists and is being tested in the game.
The code and the download will appear here with the first release.

- Your songs (mp3, flac, wav, ogg, m4a) as **new tracks** — tick where each one plays: races, pursuits.
- Songs from **YouTube / YT Music / Spotify**, like in Unbound and Heat Soundtrack.
- **Restore original** — the program keeps a copy of the game's original music files; one button and the game is back as it was.
- No Frosty Mod Manager, no keys: Hot Pursuit isn't on Frostbite.
- **Offline only** — mods are for single player.
